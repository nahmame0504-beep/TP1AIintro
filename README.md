# TP 1 : Pratique du NLP — Prétraitement du texte

Ce dépôt contient le travail pratique dédié au nettoyage et à la préparation de données textuelles brutes pour le Traitement Automatique du Langage Naturel (NLP).

##  Objectifs pédagogiques
À la fin de ce TP, nous sommes capables de :
- Nettoyer et normaliser un texte (passer en minuscules, supprimer la ponctuation).
- Tokeniser un texte et éliminer les mots vides (*stopwords*).
- Lemmatiser le texte pour réduire les mots à leur forme canonique.
- Utiliser les bibliothèques incontournables du NLP : **NLTK**, **spaCy**, et **scikit-learn**.
